# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed
- Reorganize six skills into architecture, engineering, and design domains.
- Adopt a vendor-neutral community catalog and external pull request guidelines.
- Normalize required skill headings while preserving existing workflow content.

### Added
- Fresh context recovery and delegation scope gate in the engineering catalog.
- Primary-source attribution ledger, PR template, and dependency-free validation CI.
- README badges, domain catalog links, installation examples, and host-specific quick starts.
- Contributor onboarding and aligned repository rules for validation, source attribution, and isolated Git operations.

### Removed
- Public packaging script and distributions; packaging belongs in the private factory.

## [1.0.0] - 2026-11-23

### Added
- Initial open-source release of 4 modular skills:
  - `software-architecture-lead`
  - `fullstack-web-playbook` (with 4 progressive-disclosure reference guides)
  - `design-architect` (with 6 progressive-disclosure reference guides)
  - `ui-motion-craft`
- Initial ZIP packaging support (removed in the unreleased community hub restructure).
- Repository documentation (`README.md`, `AGENTS.md`, `CONTRIBUTING.md`, `LICENSE`).
